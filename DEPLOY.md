# Как открыть MeterApp с телефона (без постоянно включённого ПК)

Сейчас программа крутится только на вашем компьютере. Чтобы заходить **с телефона из любой сети**, нужно один раз выложить её в интернет на **бесплатный** хостинг.

Ниже — самый простой путь: **один сайт на Render** (и API, и интерфейс вместе).

---

## Что получится

- Адрес вида: `https://meterapp-xxxx.onrender.com`
- Открываете его в браузере телефона — работаете как обычно
- Компьютер **не нужно** держать включённым
- На бесплатном тарифе сайт «засыпает» без запросов ~15 минут: первый вход после паузы может занять 30–60 секунд

---

## Шаг 0. Аккаунты (бесплатно)

1. **GitHub** — https://github.com (если ещё нет)
2. **Render** — https://render.com (вход через GitHub удобнее)

---

## Шаг 1. Загрузить код на GitHub

### 1.1. Создать репозиторий

1. Зайдите на github.com → **New repository**
2. Имя, например: `meter-app`
3. Public → **Create repository**

### 1.2. Залить папку проекта

**Вариант через сайт GitHub (проще без git):**

1. В новом репозитории: **uploading an existing file**
2. Перетащите **содержимое** папки `meter-app` (backend, frontend, Dockerfile, render.yaml, …)
3. Commit

**Вариант через Git (если умеете):**

```powershell
cd C:\Projects\PLAT\meter-app
git init
git add .
git commit -m "MeterApp 1.0"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/meter-app.git
git push -u origin main
```

---

## Шаг 2. Создать сервис на Render

1. https://dashboard.render.com → **New +** → **Web Service**
2. Подключите GitHub и выберите репозиторий `meter-app`
3. Настройки:

| Поле | Значение |
|------|----------|
| Name | `meterapp` (любое) |
| Region | Frankfurt или ближайший |
| Runtime | **Docker** |
| Dockerfile Path | `./Dockerfile` |
| Instance type | **Free** |

4. Environment Variables → **Add**:

| Key | Value |
|-----|--------|
| `SECRET_KEY` | любая длинная случайная строка (например 40 символов) |
| `PYTHONPATH` | `/app` |

5. **Create Web Service** → дождитесь окончания сборки (5–15 минут).

6. Когда статус **Live**, сверху будет URL:

```text
https://meterapp-xxxx.onrender.com
```

Проверки:

- `https://ВАШ-URL/` — должна открыться форма входа MeterApp  
- `https://ВАШ-URL/docs` — документация API  
- `https://ВАШ-URL/health` — `{"status":"healthy",...}`

---

## Шаг 3. Телефон

1. Откройте этот URL в **Chrome** на Android (или Safari на iPhone).
2. Зарегистрируйтесь (можно тот же email, что локально — база на сервере **новая**, данные локальные сами не перенесутся).
3. Меню браузера → **«Установить приложение»** / **«На экран Домой»** — иконка как у приложения.

---

## Перенос старых данных с компьютера

База на Render **пустая**. Чтобы перенести историю:

1. Локально: **Ещё → Полный бэкап (ZIP)** или Excel-экспорт.
2. На сервере: заново создайте квартиру → **Импорт Excel** (если сохраняли xlsx) или вводите заново.

(Автоимпорт ZIP-бэкапа можно добавить позже по запросу.)

---

## Если сборка на Render упала

- Смотрите **Logs** в Render — пришлите текст ошибки.
- Убедитесь, что в корне репозитория есть файлы: `Dockerfile`, `backend/`, `frontend/`.
- Free-план иногда долго ставит зависимости — подождите и нажмите **Manual Deploy**.

---

## Альтернатива: только backend на Render + frontend на Vercel

См. старый вариант в истории проекта. Для вас **удобнее один URL** (Docker выше).

---

## Важно

| Тема | Пояснение |
|------|-----------|
| Компьютер | После деплоя **не нужен** для работы с телефона |
| Бесплатный Render | «Сон» после простоя, данные SQLite могут сброситься при **пересборке** — делайте бэкап |
| Пароль | Не используйте тот же, что в банке; для теста можно простой |
| Интернет | Нужен на телефоне (Wi‑Fi или мобильный) |

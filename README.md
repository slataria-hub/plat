# MeterApp 1.0 — показания счётчиков и квитанции ЖКХ

## Возможности

1. Напоминания сдать показания (день месяца настраивается)
2. Сверка объёмов квитанции и расхода по счётчикам
3. Ожидаемый платёж (среднее за N месяцев)
4. История тарифов с дельтой
5. Быстрый ввод показаний с главной
6. Заметки к периоду
7. Экспорт PDF/TXT отчёта
8. Сравнение двухтариф / однотариф
9. Несколько лицевых счетов и провайдеров
10. Ссылки на ЛК (ЕИРЦ, Мосэнергосбыт…) — без платного API
11. Семейный доступ (приглашение, только просмотр)
12. Виджет-сводка (+ PWA)
+ OCR, импорт Excel, бэкап ZIP, аналитика
